ORBIT — INTERACTIVE SPACE EXPLORER (V2)

Run:
1. Extract this ZIP.
2. Open the folder in VS Code.
3. Open index.html using Live Server (or double-click index.html).

Pages:
- index.html: cinematic landing page with animated planet/orbits
- planets.html: 8 clickable planet cards; each opens a detailed dossier with facts and related exploration missions
- missions.html: clickable mission archive; each opens mission details, facts and highlights
- gallery.html: animated CSS space-art gallery
- about.html: project information and orbital animation

Files:
- style.css: all layout, responsive styling and animations
- script.js: navigation, planet data, mission data and modal interactions

Technology: HTML5, CSS3, Vanilla JavaScript. No external libraries required.
Planet facts and mission details are educational summaries. Some moon counts can change as new discoveries are confirmed.
